## 判断

- 元PNGはGitへ含めず、公開画像だけをWebPで管理する。変換時にExifなどの付随メタデータを引き継がず、公開不要な情報を残さないため。
- 公開DBの切り替えはバックアップと書き込み停止を伴うため、画像準備とは分けて実行する。

## 検証

- 10画像が1086x1448のWebPで、アルファチャンネルを保持していることを確認した。
- 10画像にExif、ICC、XMPメタデータが残っていないことを確認した。
- `npm test`で38件すべて成功し、`npm run typecheck`と`npm run lint`も成功した。
- arm64 Nodeで`npm run build`を実行し、Next.jsの本番ビルドが成功した。
- ビルド済みアプリで10画像が`200 image/webp`を返すこと、代表画像がブラウザで欠けなく表示されること、画面遷移時にエラーがないことを確認した。
