# iPhone Safari Production実機テスト

最終更新: 2026-08-29

公開URL `https://nomilog-eight.vercel.app` を、iPhoneのSafariで確認するための手順です。テスト用データを残さず、普段使うアカウントや運営アカウントを削除しないことを優先します。

## 始める前

1. iPhoneでSafariを開き、プライベートブラウズの新しいタブを使う。
2. ふだん使う「のみログ」アカウント、運営用アカウントではログインしない。
3. テスト専用に、次のようなGmailの`+`付き別名を2つ用意する。メールは同じ受信箱へ届く。
   - 投稿者: `melongreen0904+nomilog-iphone-author@gmail.com`
   - 閲覧者: `melongreen0904+nomilog-iphone-reader@gmail.com`
4. すでに同じ別名を使った場合は、末尾を日付などへ変える。例: `+nomilog-iphone-author-0829`。
5. 本人の顔、氏名、住所、学校名、連絡先、位置情報が写る写真や文章は投稿しない。レビュー写真はこのテストでは追加しない。

## 確認手順

### 1. 匿名での閲覧

1. `https://nomilog-eight.vercel.app` を開く。
2. ホームのロゴ、検索欄、カテゴリ、今週のランキング、最新のレビュー、下部ナビが横にはみ出さず表示されることを確認する。
3. 検索から「午後の紅茶」または任意の商品名を検索し、結果を開く。
4. 商品詳細で商品画像、星評価、甘さ・炭酸・コスパの表示を確認する。
5. `https://nomilog-eight.vercel.app/products/not-a-product` を開き、「検索画面から別の商品を探してください。」という案内が表示されることを確認する。

### 2. 投稿者アカウントで登録・投稿

1. 下部ナビの「マイページ」から「新規登録」を押す。
2. 投稿者用メールアドレスを入力し、届いた6桁コードで登録する。
3. マイページに戻ること、表示名が編集できることを確認する。
4. 商品詳細を開き、「レビュー」を押す。選んだ商品名が投稿画面に入っていることを確認する。
5. 星、甘さ、炭酸、コスパ、シーン、購入場所を選び、コメントへ`実機テスト用の投稿です。削除予定です。`と入力する。写真は追加しない。
6. 投稿ボタンを押し、確認ダイアログで投稿を確定する。
7. 商品詳細とレビュー一覧で、投稿したレビューと評価が表示されることを確認する。
8. マイページの「ログアウト」で投稿者アカウントからログアウトする。

### 3. 閲覧者アカウントでいいね・通報

1. 閲覧者用メールアドレスで新規登録する。
2. 同じ商品詳細またはレビュー一覧で、投稿者のテストレビューを開く。
3. ハートを1回押し、赤色になり、少しアニメーションして、件数が増えることを確認する。もう1回押し、元に戻ることも確認する。
4. もう一度ハートを押して赤色に戻す。
5. レビューの通報を開き、理由を1つ選んで送信する。送信後にエラー画面にならないことを確認する。
6. マイページ、通知設定、お気に入り一覧を開き、横はみ出しや押せないボタンがないことを確認する。

### 4. 一時アカウントの削除

アカウント削除は元に戻せません。**必ず上のテスト専用アカウントだけで実行し、普段使うアカウントでは実行しないでください。**

1. 閲覧者アカウントで「マイページ」から「アカウント管理」を開く。
2. 説明文を確認し、入力欄へ`アカウントを削除`と完全一致で入力する。
3. 「アカウントを完全に削除」を押し、Safariの確認ダイアログで確定する。
4. ログイン前の状態へ戻ることを確認する。同じ閲覧者メールで再登録・再ログインは試さない。
5. 投稿者アカウントでログインし直し、同じ手順でアカウントを削除する。
6. 匿名状態で商品詳細を開き、テストレビューがなくなり、件数・平均評価が元に戻っていることを確認する。

削除に失敗した場合は、削除を繰り返さず、その画面のスクリーンショットを撮って手順番号と一緒に伝えてください。こちらでProductionの残データとエラーを確認します。

## 記録して伝えてほしいこと

次の形式で十分です。メールアドレス、6桁コード、氏名、スクリーンショットに映った個人情報は送らないでください。

```text
iPhone機種 / iOS: 例 iPhone 13 / iOS 18.x
Safariの表示: 正常 / 横はみ出しあり / ボタンが押せない
1. 匿名閲覧: OK / NG（内容）
2. 登録・投稿: OK / NG（内容）
3. いいね・通報: OK / NG（内容）
4. アカウント削除: OK / NG（内容）
気になった点: あれば短く
```

不具合の画面を送る場合は、Safariのアドレスバー、通知、メール、個人情報が写らないように切り取るか塗りつぶしてください。
